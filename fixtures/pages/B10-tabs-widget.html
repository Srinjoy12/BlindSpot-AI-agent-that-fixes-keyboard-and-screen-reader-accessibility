Product documentation

Overview

BlindSpot automatically finds and fixes keyboard accessibility barriers on your web pages. It drives a real browser with the keyboard and runs deterministic detectors to find issues.

Keyboard crawl
Tabs through every focusable element, recording position and focus state
Detectors
Eight deterministic checks for traps, invisible focus, and missing names
AI analysis
Nemotron models explain findings and propose fixes

Installation

Install BlindSpot using npm:

npm install @blindspot/cli

Then run your first audit:

npx blindspot audit https://yoursite.com

Configuration

Create a blindspot.config.js in your project root:

maxStops
Maximum number of Tab stops to crawl (default: 150)
severity
Minimum severity to report: blocker, major, or minor
